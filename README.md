# AI Student Early Warning System

## 📌 About

The AI Student Early Warning System is a machine learning based application that helps identify students who may be at academic risk.

It analyzes student academic factors such as attendance, marks, previous performance and other inputs to estimate the student's risk level.

## 🚀 Features

- Student performance analysis
- AI/ML based risk prediction
- High, Medium and Low risk classification
- Student-wise performance details
- Risk summary dashboard
- Academic guidance suggestions
- Interactive Streamlit interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Scikit-learn
- Machine Learning

## ▶️ How to Run

1. Clone this repository.
2. Install the required Python packages.
3. Run the Streamlit application.

```bash
streamlit run app.py
